# [예시] 형식 본보기 — U-12 내 학습 수강 포기

> 이것은 **형식 예시**입니다. 화면 이름·주소·문구를 그대로 베끼지 말고, 실제 템플릿·Controller를 읽고 확인한 것으로 쓰세요.
> 아래 문구는 사람이 기억으로 적은 것이라 실제와 다를 수 있습니다.

## 1. 이슈를 확인한다
- 이슈 #348 체크리스트의 "U-12 내 학습 (수강 중·완료 탭, 수강 포기 M-12)"
- 주소: `/my/learning`

## 2. 준비하고 로그인한다
- develop 최신, SQL 01 → 02, 앱 실행 `http://localhost:8080`
- `/login` 에서 학습자로 로그인
- `/courses/1` 에서 수강 시작 (수강 중인 코스가 있어야 카드가 보임)

## 3. 정상 흐름
- a. 위쪽 메뉴 "내 학습" 클릭 → 주소가 `/my/learning`
- b. "수강 중" 탭 코스 카드에서 "수강 포기" 클릭
- c. 확인 모달 → "취소" → 모달이 닫히고 카드 그대로
- d. 다시 "수강 포기" → "포기하기"
- 보이면 정상: 모달 제목, 토스트, 카드가 목록에서 사라짐, 주소 그대로
- 이상하면: 모달이 안 뜸, 카드가 안 사라짐, 오류 화면, 토스트가 두 번

## 4. 예외 흐름
- a. 포기한 코스의 수업 주소를 직접 입력
- b. "완료" 탭에 포기한 코스가 없는지
- c. 새로고침 후 토스트가 다시 뜨지 않는지
- d. 로그아웃 후 `/my/learning` 열기 → 로그인 화면이어야 함

## 5. 아쉬운 점 찾기
- 모달 문구가 "진행 기록은 남는다"를 알려 주는지
- 포기한 뒤 다음에 무엇을 할지 안내가 있는지 (빈 상태)
- 클릭 수, 버튼이 눈에 띄는지, 폭 약 400px에서 깨지는지

## 6. 결과 기록
| 종류 | 올리는 곳 |
|---|---|
| 이상 없음 | 체크리스트 체크 + 기록 표 한 줄 |
| 동작 문제 | `🐛 버그 제보` (재현 방법에 계정과 순서를 번호로) |
| 아쉬운 점 | `🔧 작업`, 제목 `[개선]`, P3 |
| 보기 문제 | `🔧 작업` + `🎨 design`, 화면 ID와 스크린샷 |
- 올린 이슈 번호를 QA 이슈의 "발견한 이슈"에 한 줄로 적기
