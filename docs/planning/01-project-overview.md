## 2. 기획 배경

### 2-1. 문제 정의 (해결하고자 하는 문제)

바이브코딩 교육은 숙련도와 관계없이 같은 콘텐츠를 보여주고, 학습이 끝나도 실력을 증명할 방법이 수료증뿐이다.

1. **숙련도에 맞는 학습 경로가 없다.** AI 코딩 경험 수준에 따라 필요한 학습이 다른데도, 기존 교육은 초보·중급·숙련 사용자를 같은 콘텐츠로 묶는 경우가 많다.
2. **수료증으로는 실력을 증명할 수 없다.** 학습 후 실제로 무엇을 만들 수 있는지, AI를 얼마나 잘 통제하고 검증할 수 있는지는 수료증만으로 보여주기 어렵다.

### 2-2. 대상

학습자는 숙련도에 따라 네 유형으로 나눈다.

| 학습자 유형 | 상태 |
| --- | --- |
| 입문 학습자 | 바이브코딩을 거의 해 본 적이 없고, AI에게 무엇을 어떻게 지시해야 할지 모름 |
| 제어가 필요한 학습자 | 결과물은 만들어 봤지만 AI가 수정 범위를 벗어나거나 프로젝트가 쉽게 꼬임 |
| 구조화가 필요한 학습자 | 원하는 기능은 구현하지만 큰 프로젝트의 작업 분할, 맥락 관리, 테스트, 코드 품질 관리가 필요함 |
| 숙련 학습자 | AI 코딩 경험이 충분하고 최신 모델·에이전트·컨텍스트 관리·개발 워크플로를 빠르게 실험하고 싶음 |

### 2-3. 현재 해법

지금 바이브코딩을 배우려는 사람은 강의, 부트캠프, 무료 단기 과정, 리뷰 플랫폼 중 하나를 고르거나, 아예 배우지 않고 AI 앱 빌더를 쓴다.

| 유형 | 대표 서비스 | 제공 방식 |
| --- | --- | --- |
| 국내 강의 플랫폼 | 인프런, 패스트캠퍼스 | 카테고리별 VOD 강의, 관심 분야 기반 강의 추천, 로드맵, 커뮤니티와 유료 멘토링. 패스트캠퍼스 AI 월드는 퀴즈·실습에 캐릭터·배지 수집 같은 게임 요소를 붙였다 |
| 국내 부트캠프 | 코드잇 스프린트, 팀스파르타 | 국비지원 장기 과정. 실시간 라이브 강의, 현직자 코드 리뷰, 팀 프로젝트 포트폴리오, 취업 지원 |
| 1:1 수익화 강의 | 크몽 | 개인 강사가 1:1 상담 후 맞춤 커리큘럼(기본 강의, 토이·실전 프로젝트)을 판매 |
| 해외 코호트 과정 | Maven Vibe Coding Bootcamp | 2.5주 라이브 코호트, 매일 짧은 레슨, 결과물에 대한 강사 피드백 (약 $799) |
| 빅테크 무료 과정 | Google×Kaggle, DeepLearning.AI, Anthropic Academy | 무료 단기 강좌, 선택형 캡스톤, 수료증·배지 |
| 리뷰 기반 학습 플랫폼 | Exercism, Frontend Mentor | 과제를 제출하면 자원봉사 멘토·커뮤니티가 리뷰. Frontend Mentor는 AI 코드 리뷰도 제공 |
| 기관용 실습 플랫폼 | 엘리스 LXP | 설치 없는 브라우저 실습, 자동채점, 학습 데이터 대시보드 |
| 대체재: AI 앱 빌더 | Lovable | 학습 없이 자연어로 앱을 만들고 배포, 게시 전 보안 점검 |

### 2-4. 기존 방식의 불편함

기존 서비스는 "만드는 법을 가르치고 수료증을 주는" 데 머물러 있어, AI로 만든 결과물과 그 과정을 숙련도에 맞게 검증받을 곳이 없다.

| 불편 | 근거 |
| --- | --- |
| 결과물 피드백이 없거나 강사에 따라 다르다 | 패스트캠퍼스는 VOD 중심이라 개인 결과물 피드백이 구조적으로 어렵다. 인프런·크몽은 검증이 강사 역량에 달려 있고 공통 평가 기준이 없다 |
| 숙련도별로 이어지는 바이브코딩 경로가 없다 | 패스트캠퍼스는 강의별로 따로 판매된다. 코드잇·스파르타는 전통 개발자 양성·취업 중심이고, Exercism은 입문자용이 아니다 |
| AI를 어떻게 통제했는지는 평가하지 않는다 | Frontend Mentor는 UI 구현만, Exercism은 알고리즘·문법만 본다. 엘리스의 자동채점은 정답이 없는 AI 코딩 프로젝트에 맞지 않는다 |
| 보안은 사용자 몫으로 남는다 | Lovable로 만든 웹앱 1,645개 중 170개에서 개인정보·API 키가 노출됐고, 점검 권고를 적용할지는 사용자 재량이다 |
| 학습 증빙이 수료증에 그친다 | 패스트캠퍼스는 수료 여부 위주, Anthropic Academy 수료증은 이수 증명일 뿐이다. 크몽·Maven은 결과가 공개 포트폴리오로 남지 않는다 |
| 일회성이라 끝까지 가지 않는다 | Google×Kaggle 과정은 5일짜리이고 캡스톤 제출률이 등록 대비 약 2%다. Maven은 2.5주 뒤 이어지는 성장 경로가 없다 |
| 콘텐츠가 업데이트되지 않는다 | 인프런 강사 답변: "VOD 강의에는 업데이트가 예정에 없다" |
| 피드백 있는 학습은 비싸거나 오래 기다려야 한다 | Maven 약 $799, 코드잇 스프린트는 주당 학습량이 많아 학업·직장과 병행하기 어렵다. Exercism은 리뷰를 1주 넘게 기다린 사례가 있다 |

## 3. 목표

**핵심 방향:** "AI에게 코드를 시키는 방법"만 가르치는 것이 아니라, AI와 함께 소프트웨어를 제대로 설계·구현·통제·검증하는 능력을 학습하고 증명하게 한다.

바이브로그는 영상 시청 중심이 아니라, **직접 풀고 만들어 제출하고 기준을 통과해야 다음 단계가 열리는** 무료 학습 플랫폼을 만든다.

| 해결하고자 하는 문제 | 바이브로그의 해결책 |
| --- | --- |
| 숙련도에 맞는 학습 경로가 없다 | **숙련도 진단과 4개 트랙** (Starter / Controller / Builder / Explorer) |
| 수료증으로는 실력을 증명할 수 없다 | **수료증 대신 포트폴리오**: 코스마다 결과물 포트폴리오가 쌓인다 |

**만들지 않는 것**

- AI 호출 비용이 드는 서비스 기능: 무료 서비스이므로 퀴즈 채점, 진도, 보상은 규칙 기반으로 처리한다.
- 도구 사용법 강의: 빅테크가 무료로 더 빠르게 제공하므로 "도구 노트"로 연결만 한다.
- 영상·이미지 생성 AI 교육: 결과물은 코딩 결과물로 한정한다.
- 취업 보장형 장기 부트캠프: 기관이 바이브로그를 도구로 쓰는 구조(기관 관리자)로 접근한다.

## 4. 핵심 기능

### 4-1. 메인 비즈니스 로직: 학습자 한 명의 흐름

> 2026-10-30 발표 후 변경: 퀴즈 통과 기준(정답률 50% 이상), 모의고사·오답 분석 리포트, 월간 콘테스트, 추천 랭킹을 추가했다.
> 2026-11-03 변경: 학습 구조를 트랙 → 코스 → 수업 → 활동으로 정했다. 수업 안에서 개념과 퀴즈를 반복하고 수업마다 모의고사를 본다. 과제와 포트폴리오는 "포트폴리오"로 용어를 통일하고 코스 마지막에 한 번 제출한다.
> 2026-11-03 엔티티 확정(D1~D10) 반영: 커뮤니티를 일반 게시판(자유게시판 / 질문·답변 / 작품 공유)으로 바꿨다.

학습자는 진단으로 트랙을 추천받아 코스를 고르고, 수업마다 개념과 퀴즈를 반복한 뒤 모의고사로 약한 부분을 확인한다. 모든 수업을 마치면 포트폴리오를 만들어 제출하고 코스를 마친다.

**학습 구조 예시**

```
Controller 트랙
 └ 코스: AI 작업 범위 통제하기
    ├ 수업 1: 수정 범위를 지정해서 요청하기
    │   ├ 활동: 개념 a
    │   ├ 활동: 퀴즈 (정답률 50% 이상 통과)
    │   ├ 활동: 개념 b
    │   ├ 활동: 퀴즈 (정답률 50% 이상 통과)
    │   ├ 활동: 개념 c
    │   ├ 활동: 퀴즈 (정답률 50% 이상 통과)
    │   └ 모의고사 → 오답 분석 리포트
    ├ 수업 2: ...
    └ 포트폴리오 → 코스 완료
```

![메인 비즈니스 로직](../images/프로젝트%20소개_발표후_4-1.%20메인%20비즈니스%20로직%282026-11-03%29.png)

**메인 흐름**

1. **가입 → 로그인**
2. **진단 → 트랙 추천 → 코스 선택:** 진단 설문으로 트랙을 추천받고, 추천 트랙이나 다른 트랙에서 학습할 코스를 고른다.
3. **개념 활동:** 글과 그림 위주로 개념 하나를 배운다.
4. **퀴즈 풀이:** 방금 배운 개념을 퀴즈로 확인한다. 정답률 50% 이상이어야 통과하고 다음 개념이 열린다. 틀린 문제의 비율로 약한 부분을 확인해 다시 푼다.
5. **모의고사:** 수업의 마지막 퀴즈를 통과하면 그 수업 전체 내용으로 된 모의고사가 열린다.
6. **오답 분석 리포트:** 모의고사 결과를 개념별로 분석해, 어떤 개념이 약한지와 어느 개념을 다시 보면 되는지 보여준다. 리포트를 확인하면 다음 수업이 열린다.
7. **포트폴리오 과제:** 마지막 수업의 리포트를 확인하면 코스의 포트폴리오 과제가 열린다. 코스 주제와 학습 목표에 맞는 과제가 제시되고, 서비스가 스텝을 제공하면 학습자는 그 순서대로 직접 따라가며 만든다. 과제와 함께 평가 에이전트의 설명이 열려, 결과물이 목표에 맞는지, 성능이 좋은지, 어느 정도로 괜찮은지 스스로 점검한다.
    - 각 에이전트는 그 코스의 학습 목표에 특화되어 있다.
    - 서비스가 에이전트를 직접 돌려주지는 않는다. 학습자가 자기 환경에 세팅해 실행한다.
    - 부족한 점이 나오면 보완·수정하고 다시 실행한다.
8. **포트폴리오 제출:** 결과물 링크 등을 올리면 그대로 포트폴리오 카드로 등록되고 코스가 완료된다. 공유 여부는 자유다.

수업 안에서는 3~4를 개념 수만큼 반복하고, 코스 안의 수업마다 3~6을 반복한다. 마지막 수업 뒤 7~8을 마치면 코스 완료와 함께 포트폴리오가 완성된다.

**추가 로직**

- **커뮤니티 게시판:** 자유게시판, 질문·답변, 작품 공유 게시판에 글과 사진을 올리고 댓글·답글로 이야기한다. 작품 공유 글에는 서로 추천(GitHub 스타 방식)을 남길 수 있고, 추천 수가 많은 글은 추천 랭킹에 오른다.
- **월간 콘테스트:** 매달 플랫폼이 주제를 내고, 학습자가 출품작에 투표한다. 1·2·3등은 배지를 받는다.
- **쪽지:** 좋은 상대에게 쪽지를 보내 자기 작품의 평가를 부탁하는 등 대화를 할 수 있다.
- **포트폴리오 템플릿:** 일반적인 루트(코스를 듣고 그에 맞는 포트폴리오를 내는 것)가 아니어도, 개인적으로 만든 작품을 템플릿에 맞춰 올려 저장·공유할 수 있다.

### 4-2. 핵심 기능 정리

| 기능 | 내용 | 해결하는 불편 |
| --- | --- | --- |
| 1. 트랙 추천 · 코스 선택 | 진단으로 4개 트랙 중 하나를 추천받고, 트랙 안의 코스를 골라 학습한다 | 초보와 숙련자가 같은 콘텐츠를 본다 |
| 2. 수업 단위 학습 | 코스는 수업의 연속이다. 수업 하나는 개념(글·그림 위주) → 퀴즈(정답률 50% 이상 통과, 틀린 문제 비율로 약한 부분 확인)를 개념 수만큼 반복하는 활동으로 구성된다. 퀴즈를 통과해야 다음 개념이 열린다 | "따라 만들기"로 끝난다 |
| 3. 모의고사 · 오답 분석 리포트 | 수업 끝마다 모의고사를 보고, 리포트가 개념별 정답률로 약한 부분과 다시 볼 개념을 알려준다. 리포트를 확인해야 다음 수업이 열린다 | 학습이 끝나도 어디가 부족한지 모른다 |
| 4. 포트폴리오 과제 · 평가 에이전트 | 모든 수업을 마치면 코스 학습 목표에 맞는 포트폴리오 과제와 평가 에이전트 설명이 열린다. 학습자는 스텝 가이드대로 만들고, 자기 환경에서 에이전트를 실행해 목표 부합·성능을 확인하고 보완한다 | 결과물을 제대로 검증했는지 피드백받기 어렵다 |
| 5. 포트폴리오 제출 | 결과물을 제출하면 포트폴리오 카드로 등록되고 코스가 완료된다(코스당 1개). 공유 여부는 자유다 | 수료증은 실력을 증명하지 못한다 |

## 5. 기대효과

| 사용자 유형 | 얻는 이득 |
| --- | --- |
| 입문 학습자 | 막연하게 AI에게 코드를 요청하는 것이 아니라 요구사항을 작은 단위로 전달하고 결과를 확인하는 기본 습관을 익힌다. |

| 구조화가 필요한 학습자 | 큰 기능을 작업 단위로 나누고 테스트·보안·리팩터링까지 포함해 AI와 안정적으로 프로젝트를 개발하는 방법을 익힌다. |
| 숙련 학습자 | 빠르게 변하는 AI 개발 도구와 워크플로를 같은 과제로 비교·검증하고 자신의 개발 방식에 적용할 근거를 얻는다. |
