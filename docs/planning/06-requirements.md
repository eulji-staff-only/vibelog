## 0. 기준

### 0-1. 우선순위

| 우선순위 | 의미 | 이 서비스에서의 기준 |
| --- | --- | --- |
| **P1 (Must)** | 없으면 서비스를 오픈할 수 없는 핵심 기능 | 메인 흐름(가입 → 진단·트랙 추천 → 코스 선택 → 수업(개념 → 퀴즈 반복 → 모의고사 → 오답 분석 리포트) 반복 → 포트폴리오 제출 → 코스 완료)과 그 흐름을 운영하는 데 꼭 필요한 운영자 기능 (Q4), 일반 게시판의 글·사진·댓글 (D2) |

## 1. 전제

### 1-1. 학습 구조와 메인 흐름 (2026-11-03 변경)

**학습 구조:** 트랙 → 코스 → 수업 → 활동

```
Controller 트랙
 └ 코스: AI 작업 범위 통제하기
    ├ 수업 1: 수정 범위를 지정해서 요청하기
    │   ├ 활동: 개념 a
    │   ├ 활동: 퀴즈 (정답률 50% 이상 통과)
    │   ├ 활동: 개념 b
    │   ├ 활동: 퀴즈 (정답률 50% 이상 통과)
    │   ├ 활동: 개념 c
    │   ├ 활동: 퀴즈 (정답률 50% 이상 통과)
    │   └ 모의고사 → 오답 분석 리포트
    ├ 수업 2: ...
    └ 포트폴리오 → 코스 완료
```

**메인 흐름:** 가입 → 진단(트랙 추천)·코스 선택 → 수업(개념 → 퀴즈 반복 → 모의고사 → 오답 분석 리포트 확인) 반복 → 포트폴리오 제출 → 코스 완료

### 1-2. 팀 결정

| 항목 | 결정 |
| --- | --- |
| 사용자 | 비회원, 학습자, 운영자. 기관 관리자·리뷰어 역할은 없다 |
| 트랙 | Starter / Controller / Builder / Explorer 4개 트랙이 있고, 트랙 안에 여러 코스가 있다. 진단은 트랙을 추천하고, 학습자는 어떤 트랙의 코스든 고를 수 있다 (2026-11-03, D3) |
| 카테고리 | 코스는 트랙 하나와 카테고리 하나에 속한다. 트랙과 카테고리는 따로 둔다 (D4) |
| 퀴즈 형식 | 객관식 4지선다만 둔다. 단답형은 쓰지 않는다. 문항은 코드 빈칸 채우기 / 개념 문제 / 결과 유추하기 / 낚시 문제 4가지 표시 유형으로 보여주고, 퀴즈는 수업 화면과 따로 있는 퀴즈 화면에서 푼다 (D6, D9, 2026-11-04 화면 설계 반영) |
| 수업 안 잠금 | 수업은 개념과 퀴즈가 번갈아 놓인 활동과 마지막 모의고사로 이루어진다. 퀴즈를 통과(정답률 50% 이상)해야 다음 개념이 열리고, 마지막 퀴즈를 통과하면 모의고사가 열린다 (2026-11-03) |
| 수업 간 잠금 | 모의고사를 보고 오답 분석 리포트를 확인하면 다음 수업이 열린다. 모의고사에는 통과 점수를 두지 않는다 (2026-11-03) |
| 포트폴리오 | 과제와 포트폴리오를 "포트폴리오"로 통일한다. 코스의 마지막 수업 리포트를 확인하면 포트폴리오가 열린다. 실습 가이드·평가 에이전트 설명·FAQ는 포트폴리오에서 제공하고, 결과물을 제출하면 그대로 포트폴리오 카드로 등록된다 (2026-11-03) |
| 코스 완료 조건 | 모든 수업의 모의고사 응시 + 오답 분석 리포트 확인 + 포트폴리오 제출 (Q21, 2026-11-03 변경, D1). 활동·수업의 열림과 완료 시각은 저장해 순서가 바뀌어도 다시 잠그지 않고, 진행률과 코스 완료 여부는 학습 기록에서 계산한다. 코스 완료는 처음 조건을 채운 시각을 기록한다 (2026-11-04) |
| 커뮤니티 | 일반 게시판(자유게시판 / 질문·답변 / 작품 공유)이다. 추천·즐겨찾기·랭킹은 작품 공유 게시글 기준이고, 콘테스트 출품과 동료 리뷰는 포트폴리오 기준이다 (D2) |
| 평가 에이전트 | 서비스는 설명과 설정 파일만 준다. 실행은 학습자 환경에서 하고, 서비스가 결과를 자동으로 받지 않는다. 학습자는 제출할 때 점검 결과를 선택 항목으로 직접 적을 수 있다 (Q17, Q18, FR-PRT-003) |
| 게이미피케이션 | XP·레벨·연속 학습 일수는 두지 않는다. 배지는 월간 콘테스트 1·2·3등에게만 준다 (Q28). 작품 공유 게시글의 추천 수 랭킹을 둔다 (Q29, D2) |
| 동료 리뷰 | 선택 기능이며 잠금과 상관없다 |
| AI 호출 | 서비스 기능에서 AI를 호출하지 않는다. 퀴즈·모의고사 채점, 리포트, 진도는 규칙 기반이다 (Q40) |
