# 업무 분석 - 사용자(2026-11-04)

학습자가 서비스에 들어와 목표(수업마다 개념·퀴즈와 모의고사로 약한 부분을 확인하고, 코스 끝에 포트폴리오를 제출해 코스 완료)를 달성하고 나갈 때까지의 핵심 여정을 정리한다. 이벤트 번호(E1-1 등)는 [이벤트 스토밍](03-event-storming.md)과 같다.

> 2026-10-30 발표 후 변경: 퀴즈 통과 기준, 모의고사·오답 분석 리포트, 월간 콘테스트, 추천 랭킹을 반영하고 XP·레벨·연속 학습 일수를 뺐다.
> 2026-11-03 변경: 학습 구조를 트랙 → 코스 → 수업 → 활동으로 정했다. 수업 안에서 개념·퀴즈를 반복하고 수업마다 모의고사를 본다. 과제와 포트폴리오를 "포트폴리오"로 합쳐 코스 마지막에 한 번 제출한다.
> 2026-11-03 엔티티 확정(D1~D10) 반영: 커뮤니티를 일반 게시판(자유게시판 / 질문·답변 / 작품 공유)으로 바꾸고, 추천·즐겨찾기·랭킹은 작품 공유 게시글 기준으로 했다. 사용자 차단은 이번 범위에서 뺐다.
> 2026-11-04 화면 설계 반영: 퀴즈를 수업 화면과 따로 있는 퀴즈 화면에서 푼다. 문항은 객관식 4지선다이고 코드 빈칸 채우기 / 개념 문제 / 결과 유추하기 / 낚시 문제 4가지 유형으로 보여준다. 문항마다 확인하며 정답·해설을 보고(확인한 문항은 답 고정), 마지막에 한 번에 제출한다.

## 1. 사용자

| 사용자 | 설명 |
| --- | --- |
| 비회원 | 랜딩, 트랙·코스 소개, 게시판 목록·상세만 볼 수 있다. 글 작성·댓글·추천은 회원만 한다 (R4, 2026-11-04) |
| 학습자 | 숙련도에 따라 입문 / 제어가 필요한 / 구조화가 필요한 / 숙련 학습자. 화면과 기능은 같고, 진단 후 추천 트랙만 다르다. 코스는 추천과 관계없이 자유롭게 고르고 여러 개를 동시에 수강할 수 있다. 수업 안에서는 퀴즈를 통과해야 다음 개념이 열리고, 모의고사를 보고 리포트를 확인해야 다음 수업이 열린다. 마지막 수업을 마치면 포트폴리오가 열린다 |

## 2. 메인 프로세스

**로그인 → 진단(트랙 추천)·코스 선택 → 수업(개념 → 퀴즈 통과 반복 → 모의고사 → 오답 분석 리포트 확인) 반복 → 포트폴리오 과제 → 평가 에이전트로 자가 점검 → 포트폴리오 제출 → 코스 완료**

### 2-1. 단계별 상세

4~5단계는 수업 안의 개념 수만큼 반복하고, 4~7단계는 코스 안의 수업마다 반복한다.

| 단계 | 학습자가 하는 일 | 서비스가 하는 일 | 화면 | 이벤트 |
| --- | --- | --- | --- | --- |
| 1. 가입·로그인 | 이메일·비밀번호 또는 GitHub·구글로 가입하고 로그인한다. 이메일 가입이면 인증 메일의 링크로 인증한다 | 계정을 만들고, 첫 로그인이면 진단 설문으로, 진행 중 코스가 있으면 내 학습으로 보낸다 | 가입, 로그인, 이메일 인증 | E1-1, E1-2, E1-7 |
| 2. 진단 | 바이브코딩 경험·겪는 문제에 대한 설문에 답한다. 건너뛸 수 있다 | 고른 보기의 트랙 점수를 더해 합계가 가장 높은 트랙 1개를 추천하고 이유와 그 트랙의 코스를 보여준다. 진단 결과(완료·건너뜀, 추천 트랙)를 저장한다 | 진단 설문, 추천 결과, 트랙 소개 | E2-1~4 |
| 3. 코스 선택 | 추천 트랙의 코스 또는 다른 트랙의 코스를 골라 수강을 시작한다. 트랙·카테고리·검색으로 찾을 수 있다 | 수강을 만들고 첫 수업의 첫 개념을 연다. 코스 상세에 플랜 일수, 수업별 활동 구성·예상 소요 시간, 수업별 모의고사·포트폴리오 안내를 보여준다 | 트랙·코스 목록, 코스 상세 | E2-5 |
| 4. 개념 활동 | 글·그림으로 된 개념을 읽고 "읽기 완료"를 누른다. 개념을 북마크할 수 있다 | 완료 처리하고 바로 뒤 퀴즈 화면으로 보낸다. 연관 개념과 도구 노트 링크를 연결한다 | 수업(개념 활동) | E3-2, E3-7 |
| 5. 퀴즈 | 퀴즈 화면에서 방금 배운 개념의 문항을 하나씩 풀고 "확인"을 눌러 정답·해설을 본 뒤, 마지막에 제출한다. 정답률 50% 미만이면 약한 부분을 보고 다시 푼다 | 확인한 문항의 답을 고정하고 정답·해설 표시, 제출하면 규칙 기반 채점, 50% 이상이면 통과 기록 → 다음 개념을 열고 수업 화면으로 돌려보낸다(마지막 퀴즈면 모의고사를 연다). 틀린 문제를 개념 태그별 비율 차트로 보여준다 | 수업(퀴즈) | E3-3~6 |
| 6. 모의고사 | 수업의 마지막 퀴즈를 통과하면 열린 모의고사를 푼다 | 규칙 기반 자동 채점 | 모의고사 | E8-1, E8-2 |
| 7. 리포트 확인 | 개념별 정답률과 약한 개념을 확인하고, 필요하면 해당 개념을 다시 본다 | 오답 분석 리포트 생성. 확인하면 다음 수업을 연다. 마지막 수업이면 포트폴리오를 연다 | 오답 분석 리포트 | E8-3~6 |
| 8. 포트폴리오 과제 | 과제와 스텝 가이드를 보며 직접 만든다. 막히면 FAQ를 본다 | 스텝 체크 상태를 저장한다 | 포트폴리오 과제, FAQ | E4-1, E4-2 |
| 9. 자가 점검 | 평가 에이전트 설명과 설정 파일로 내 환경에 세팅·실행하고, 부족하면 보완한다 | 설명과 설정 파일만 제공한다. 실행 결과는 받지 않는다 | 평가 에이전트 설명 | E4-3 |
| 10. 포트폴리오 제출 | 결과물 링크와 카드 항목(제목, 한 줄 요약, 회고, 사용한 AI 도구·모델 등)을 입력하고 공개 여부를 고른다 | 포트폴리오 카드로 저장, 공개면 공개 프로필·같은 코스 작품 보기에 노출. 코스 완료 조건을 검사한다 | 포트폴리오 제출 모달 | E5-1 |
| 11. 코스 완료 | 완료 화면을 본다. 조건이 남았으면 내 학습에서 남은 조건을 확인한다 | 모든 수업의 모의고사 응시·리포트 확인 + 포트폴리오 제출이면 코스 완료 처리 | 코스 완료 | E5-6 |

| 글쓰기 | 글쓰기 → 카테고리 선택 → 제목·본문·사진 입력 (작품 공유면 작품 링크·사용한 도구 추가) → 등록 → 게시글 상세 | E6-16, E6-17 |

| 신고 | 게시글·포트폴리오·댓글·리뷰·쪽지에서 신고(나중에 구현) → 운영자에게 전달 | E6-11 |

동료 리뷰는 선택 사항이며, 다음 수업 잠금과 상관없다. 사용자 차단은 이번 범위에서 뺐다 (D10).

### 3-3. 월간 콘테스트 · 배지

![월간 콘테스트](../images/업무분석_사용자_발표후_3-3.%20월간%20콘테스트.png)

| 프로세스 | 흐름 | 이벤트 |
| --- | --- | --- |

| 출품 | 출품 기간에 내 공개 포트폴리오 카드를 골라 출품 | E9-2 |

보상은 콘테스트 배지와 작품 공유 게시글 추천 랭킹뿐이다. XP·레벨·연속 학습 일수는 두지 않는다.

### 3-4. 포트폴리오 템플릿 (코스 없이 등록)

내 포트폴리오 → "개인 작품 추가" → 템플릿 선택 → 항목 입력(제목, 링크, 설명, 사용한 AI 도구, 회고) → 공개 여부 선택 → 저장 (E5-2)

## 4. 예외 프로세스

| 상황 | 처리 | 표시 방식 |
| --- | --- | --- |
| 로그인 실패 (이메일·비밀번호 불일치) | "이메일 또는 비밀번호가 맞지 않습니다" 표시. 어느 쪽이 틀렸는지는 알리지 않는다. 연속 실패 시 잠시 로그인을 막는다(횟수는 정책 정의서) | 폼 아래 오류 문구 |
| 가입 시 이메일 중복 | "이미 가입된 이메일입니다" + 로그인 링크 | 입력란 아래 오류 문구 |
| 이메일 인증 링크 만료 | "인증 링크가 만료됐습니다" + 인증 메일 다시 받기 버튼 | 안내 화면 |
| 이용 정지된 계정 로그인 | 정지 사유와 기간 안내, 로그인 막음 | 안내 모달 |
| 세션 만료 | 로그인 화면으로 보내고, 로그인 후 원래 화면으로 돌려보낸다 | 페이지 이동 + 토스트 |
| 진단 설문 중 이탈 | 응답을 저장하지 않는다. 다음 로그인 때 진단 또는 트랙·코스 목록 선택을 다시 보여준다 | — |
| 잠긴 수업 클릭 | "이전 수업의 모의고사를 보고 리포트를 확인하면 열립니다" 안내, 이전 수업 바로가기 | 토스트 |
| 잠긴 개념 클릭 | "앞 퀴즈를 통과하면 열립니다" 안내, 해당 퀴즈 바로가기 | 토스트 |
| 퀴즈 정답률이 통과 기준 미만 | 정답·해설과 개념별 오답 비율을 보여주고 다시 풀기 버튼 제공. 다음 개념은 잠긴 채로 두고 "퀴즈를 통과하면 다음 개념이 열립니다" 표시 | 화면 내 결과 |
| 열리지 않은 모의고사 클릭 | "이 수업의 마지막 퀴즈를 통과하면 열립니다" 안내 | 토스트 |
| 열리지 않은 포트폴리오 클릭 | "마지막 수업의 모의고사 리포트를 확인하면 열립니다" 안내 | 토스트 |
| 제출 링크 형식 오류 / 빈 값 | 제출 버튼 비활성화, "올바른 URL을 입력하세요" | 입력란 아래 오류 문구 |
| 코스 완료 조건 미충족 | 포트폴리오를 지워 조건이 빠졌으면 "이 코스의 포트폴리오를 제출하세요" + 포트폴리오 바로가기 | 내 학습 안내 카드 |
| 코스 포트폴리오 삭제 | "이 포트폴리오를 지우면 코스 완료 조건이 다시 미충족됩니다" 확인 | 확인 모달 |

| 작품 공유 글에 작품 링크가 없음 | 등록 버튼을 막고 "작품 링크를 입력하세요" | 입력란 아래 오류 문구 |

| 자기 작품에 투표 / 투표 기간 외 투표 | 투표 버튼을 막고 이유 표시 | 버튼 비활성 + 안내 문구 |
| 콘테스트 출품할 공개 포트폴리오가 없음 | "공개된 포트폴리오가 있어야 출품할 수 있습니다" + 내 포트폴리오 바로가기 | 빈 상태 화면 |
| 숨김 처리된 콘텐츠 접근 | "운영 정책에 따라 숨겨진 콘텐츠입니다" | 빈 상태 화면 |
| 비공개로 바뀐 카드 접근 | "비공개된 작품입니다" | 빈 상태 화면 |

## 5. UI 상호작용
