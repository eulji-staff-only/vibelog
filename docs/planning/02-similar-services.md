**✨ 이 사이트만의 특색** — *다른 곳엔 없는 점은?*

- 

**🛠 주요 기능** — *핵심 기능 3개 정도*

- 회원가입하고 관심분야 질문을 통해 인기 강의를 추천해줌
- 멘토링 부분은 커뮤니티 기능을 하는 것으로
- 멘토링과 커뮤니티 둘다 있는데 멘토링은 더 전문적인 부분으로 전문가를 사는 것과 같음. 결제를 하고 포트폴리오 등을 확인 받는 듯

- 유료 강의 경우 장바구니 기능이 있음
- 로드맵 만드는 게 있고 로드맵은 템플릿들을 제공하며 그걸 다른 사용자들이 보도록 공유가 가능하다
- 지식 코스 공유는 내가 커리큘럼을 만드는 것도 가능하다
- 포인트 기능도 있음. 유료라는게 포인트라 그런듯

**🔁 다른 사이트와의 공통된 기능** — *비슷한 서비스들도 다 있는 기능은?*

- 카테고리별 강의 탐색과 검색
- 커뮤니티
- 포인트
- 기업교육(B2B), 평생교육이용권, 환급 과정(AI 교육 90% 환급)
- 할인 이벤트 배너 (최대 70% 얼리버드 할인)
- AI 입문 강의 강조 (왕초보를 위한 AI Level UP)

**😣 불편한 점** — *쓰면서 답답했던 순간은?*

- 강사마다 품질과 구조가 다르다. **VOD는 업데이트되지 않는 경우가 있다**(강사 답변: "VOD 강의에는 업데이트가 예정에 없다").
- 결과물 검증은 강사 역량에 달려 있고, 플랫폼 차원의 공통 루브릭이나 포트폴리오가 없다

**💭 본인의 생각** — *우리 서비스에 참고할 점은?*

- 콘텐츠 최신성 관리(검증일·재검증), 공통 루브릭 리뷰, 결과물 누적
- 회원가입 후 관심분야 질문을 통한 강의 추천: 좋은 기능인듯
- 챌린지 항목이 있는 게 좋다
- **로그인 기능**: 우리는 포트폴리오 제작을 하고 실습을 중요하게 생각하니까 깃허브 로그인 연결을 꼭 제공하면 좋겠다.
- **온보딩 코스 추천**: 우리도 초반에 온보딩과 함께 코스 추천을 할 수 있도록 하면 좋겠다. (사용목적, 관심 분야, 세부 분야 등등)

## 🔍 패스트캠퍼스 (https://fastcampus.co.kr)

![패스트캠퍼스 메인 화면](images/패스트캠퍼스_메인.png)

**✨ 이 사이트만의 특색** — *다른 곳엔 없는 점은?*

- **AI 월드 (https://fastcampus.co.kr/ai-world)**: 게임 형식의 AI 활용 강의 모음
  - 몰입형 강의: "본 강의는 스토리와 함께 진행되는 몰입형 강의입니다. 프롤로그 영상을 시청하고 AI 월드에서 학습 여정을 시작해보세요." (강의 소개 문구)
  - 스토리: "어둠이 지배하는 AI 월드, AI 마스터들을 정화해주세요!" → 강의를 듣는 것이 캐릭터(AI 마스터)를 '정화'하는 것으로 표현됨
  - 강의마다 역사 인물 캐릭터를 붙임 (예: 「공자의 철학 - 논문 3배 더 빨리 작성하기」, 「괴테의 문장 - AI검색 맞춤 상위노출 1%를 찍는, GEO 최적화 마케팅」)
  - 처음에는 "미확인 AI 마스터"로 정보가 가려져 있고, 학습을 진행하면 단서가 하나씩 공개됨 ("첫 단서 확인하기")
  - 캐릭터·배지를 모으는 업적 시스템이 있음

**🛠 주요 기능** — *핵심 기능 3개 정도*

- AI 월드 강의는 "직접 프롬프트를 입력하고, 퀴즈와 실습으로 AI 활용능력을 키우는 강의" (페이지 소개 문구)
  - 강의 카드에 콘텐츠 수(예: 72개), 사용하는 AI 도구 아이콘(예: ChatGPT), 좋아요 수가 표시됨
  - "무료 체험하기", "이어서 학습", "복습하기" 버튼으로 학습 진행
  - 주제 예: 클로드코드, 자동매매, 옵시디언, 피그마, 모션그래픽, 블렌더

**🔁 다른 사이트와의 공통된 기능** — *비슷한 서비스들도 다 있는 기능은?*

- 카테고리별 강의 탐색과 검색
- 커뮤니티
- 포인트 (포인트 정책)
- 기업교육(B2B), 평생교육권, 국비지원
- 할인 이벤트 배너 (최대 73% 할인, 11월 1일 가격 인상 안내)
- AI 강의 강조 (GPT 무료, AI 연구소, AI 월드)

**😣 불편한 점** — *쓰면서 답답했던 순간은?*

- VOD 중심이라 **개인 결과물 피드백이 구조적으로 어렵다**. 학습 증빙은 수료 여부 위주다.
- 강의별로 따로 판매되어 숙련도에 따른 연속 경로가 약하다. 유료이고 가격대가 높다

**💭 본인의 생각** — *우리 서비스에 참고할 점은?*

- 이런것도 컨텐츠 컨셉이 좋네 (AI 월드)
- 바이브 코딩 수준별 코스가 있다는 점은 우리도 가져오기 좋은점 같고
- 무료 기본 코스 + 숙련도 진단으로 "다음에 무엇을 할지" 안내

## 🔍 코드잇 스프린트 (https://sprint.codeit.kr)

![코드잇 메인 화면](images/코드잇_메인.png)

**✨ 이 사이트만의 특색** — *다른 곳엔 없는 점은?*

- 수료 후 인턴십까지 연결: 수료 후 4주 커리어 프로그램(현직자 1:1 이력서·포트폴리오·모의면접)과 최대 5개월의 인턴십·취업 연계 지원을 제공하고, 프론트엔드 단기심화 과정은 인턴십 100% 보장을 내걸고 있음
- 개발 외 트랙도 운영: 데이터 분석가, AI 엔지니어, IT 서비스 창업, 프로덕트 디자이너 과정이 있음 (특히 창업 트랙은 드문 편)
- 지원 전에 맛보기 가능: 모든 지원자에게 프리코스 강의를 미리 제공
- Spring 백엔드 부트캠프에서 "AI 코드를 검증하고 통제하는 방법"을 다룬다(2026.11 ~ 2027.06, 약 7개월). **"AI 코드 검증·통제"라는 방향은 바이브로그와 같다**

**🛠 주요 기능** — *핵심 기능 3개 정도*

- 과정 모집·지원: 트랙별 카드에 수강 기간, 모집 상태와 함께 선착순 마감 임박 안내까지 표시
- 학습 관리: 평일 오전 9시~오후 7시 실시간 라이브 강의, 현직자 코드 리뷰, 상시 Q&A 채널, 멘탈케어·동기부여 1:1 상담
- 취업 지원: 현직자의 이력서 피드백과 모의 기술 면접, 무료 취업 자료와 커리어 인사이트 콘텐츠

**🔁 다른 사이트와의 공통된 기능** — *비슷한 서비스들도 다 있는 기능은?*

- 국비지원 + 훈련장려금: 월별 출석률 80% 이상이면 장려금이 지급되고 최대 210만 원까지 받을 수 있음 (국비 부트캠프 대부분이 같은 구조)
- 팀 프로젝트로 포트폴리오 만들기
- 현직자 멘토링, 이력서·면접 지원
- 온라인 출석 인증: ZEP 화면에 띄운 QR 코드로 출석 체크

**😣 불편한 점** — *쓰면서 답답했던 순간은?*

- 🟡 수강료, 지원 자격 같은 핵심 정보가 메인 페이지에 없어서 과정 상세 페이지까지 들어가야 확인 가능
- 🟡 '1위' 문구가 너무 많음. 지금은 취업률 1위를 쓰고, 예전 모집 공고에서는 만족도, 소비자 평가, 수강생 수 1위를 내세워서 오히려 무엇이 진짜 강점인지 흐려짐
- 🟢 주당 학습량이 많아 학업이나 직장과 병행하기 어렵다고 FAQ에서 직접 안내하고 있어서, 재직자에게는 선택지가 좁음
- 취업 중심이고, 바이브코딩만 따로 다루는 숙련도별 경로는 없다

**💭 본인의 생각** — *우리 서비스에 참고할 점은?*

- **가져올 점**: 성과 수치 → 수강생 스토리 → 선택 이유 5가지 → 혜택 → FAQ 순서로 신뢰를 차곡차곡 쌓는 메인 페이지 흐름. 과정 카드에 모집 상태와 마감 임박을 보여줘서 지원을 서두르게 만드는 방식
- **피해야 할 점**: 모든 강점을 '1위'로 표현하면 차별점이 묻힘. 비용과 자격 조건은 숨기지 말고 앞쪽에 보여주기
- **아이디어**: 재직 여부, 내일배움카드 보유 여부 등을 입력하면 지원 가능한 과정과 받을 수 있는 지원금을 바로 보여주는 기능
- 부트캠프 밖의 사람들, 또는 부트캠프 수료 후 계속 연습할 곳이 필요한 사람

## 🔍 팀스파르타 (https://spartaclub.kr)

> 스파르타코딩클럽(입문) · 내일배움캠프(국비 부트캠프 18주) · 항해플러스(주니어 개발자 과정)

![스파르타 메인 화면](images/스파르타_메인.png)

**✨ 이 사이트만의 특색** — *다른 곳엔 없는 점은?*

- 입문 과정 완강률 85.5%로 동기부여 설계가 강하다. 항해플러스는 현직 시니어 코치의 그룹 코칭과 리팩터링 과제가 있다

- 유명 기업 합격 자료를 기업명과 함께 공개: NCSOFT 백엔드 개발자 합격 이력서, 토스 UIUX 디자이너 합격 포트폴리오, 당근 PM 합격 포트폴리오, 카카오 데이터 분석가 합격 이력서 등
- 개발뿐 아니라 직무 범위가 넓음: 자료가 웹 개발, 디자인, PM, 데이터, 마케터로 나뉘어 있음
- 불만 접수 창구를 공개: 푸터에 KDT신문고 메뉴가 있음

**🛠 주요 기능** — *핵심 기능 3개 정도*

- 카테고리별 자료 다운로드: 전체, 합격 자료집, 취업 자료집, 커리어 특강, LIVE 세션 탭으로 나뉘어 있고 카드에서 바로 다운로드
- 태그로 빠르게 파악: 자료마다 Spring, Python, SQL, 포트폴리오 같은 직무·기술 태그가 붙어 있음
- 무료 특강 영상: AI 시대 채용, 디자이너 포트폴리오, 이력서에 알바 경험 넣는 이유 등 커리어 특강

**🔁 다른 사이트와의 공통된 기능** — *비슷한 서비스들도 다 있는 기능은?*

- 무료 취업 자료 메뉴: 코드잇 스프린트도 상단에 무료 취업 자료 메뉴를 두고 있음
- 국비지원 부트캠프 + 학습 관리: 운영 매니저가 학습 진도 점검, 과제 피드백, 프로젝트 지원, 멘토링 연계를 맡는 구조
- '1위' 마케팅: 이 페이지 키워드에도 취업생 수 1위, NO.1 취업 부트캠프가 들어가 있음

**😣 불편한 점** — *쓰면서 답답했던 순간은?*

- 🟡 다운로드가 브라우저에 따라 막힐 수 있음: 다운로드가 안 되면 크롬이나 사파리에서 열어달라는 안내가 있어서, 카카오톡·인스타 같은 앱 안에서 링크를 열면 핵심 기능이 안 될 가능성이 큼
- 🟡 모바일에서 화면 확대가 막혀 있음: 페이지 설정이 user-scalable=no로 되어 있어 작은 글씨를 키워 볼 수 없음
- 트랙이 React·Node·Spring 같은 **전통 개발자 양성** 중심이다. 바이브코딩 전용 숙련도 경로는 확인되지 않았다

**💭 본인의 생각** — *우리 서비스에 참고할 점은?*

- 비개발자부터 숙련자까지 이어지는 AI 코딩 경로

## 🔍 Exercism (https://exercism.org)

![Exercism 메인 화면](images/Exercism_메인.png)

**✨ 이 사이트만의 특색** — *다른 곳엔 없는 점은?*

- 완전 무료인데 실제 개발자에게 코드 리뷰를 받을 수 있어요. 학생이 코딩 문제를 풀면 자원봉사 멘토가 코드에 피드백을 줘서 지식의 빈틈을 찾게 도와주는 구조예요. 지금까지 학생 258만여 명, 멘토링 대화 40만여 건이 쌓였어요.

**🛠 주요 기능** — *핵심 기능 3개 정도*

- 언어별 트랙과 단계별 연습 문제
- 멘토 코드 리뷰 요청
- 멘토 평판 시스템: 멘토링을 하면 평판(reputation)이 쌓여요

**🔁 다른 사이트와의 공통된 기능** — *비슷한 서비스들도 다 있는 기능은?*

- 단계별 문제, 진도 표시, 커뮤니티

**😣 불편한 점** — *쓰면서 답답했던 순간은?*

- 리뷰를 기다려야 해요. 멘토가 자원봉사자라 답변까지 며칠이 걸릴 수 있다고 스스로 안내하고, 한 사용자는 마지막 제출물 리뷰를 1주 넘게 기다렸어요.
- 멘토를 따로 검증하지 않아서 가끔 나쁜 경험을 하는 경우도 있다고 해요.
- 입문자용이 아니에요. 로그인하면 처음 두 페이지에 "초보자를 위한 곳이 아니다"라고 나와요.
- 알고리즘·문법 연습 위주다. 배포된 서비스나 AI 활용 과정은 다루지 않는다

### 우리가 경쟁하지 않는 영역

| 영역 | 이유 |
| --- | --- |
| 도구 사용법 강의 (Cursor·Claude Code 메뉴 설명 등) | 빅테크가 무료로 더 빠르고 정확하게 제공한다. 바이브로그는 링크와 "도구 노트"로 연결만 한다 |
| 영상·이미지 생성 AI 교육 | 1-2 기획안의 범위 밖이다 (코딩 결과물로 한정) |
| 취업 보장형 장기 부트캠프 | 운영 비용이 크고 MVP 범위를 넘는다. 기관이 바이브로그를 도구로 쓰는 구조(기관 관리자)로 접근한다 |

### 결론 (팀원 3)

> 바이브코딩 교육 시장은 빠르게 커지고 있지만, 경쟁사는 대부분 "만드는 법을 가르치고 수료증을 주는" 영역에 몰려 있다. 빅테크는 도구 사용법을 무료로 풀고 있고, 피드백이 있는 과정은 비싸고 짧다.
> 바이브로그는 그 사이의 빈자리인 **"AI로 만든 결과물을 숙련도에 맞게 검증받고, 과정까지 증명하는 무료 상시 플랫폼"**을 목표로 한다. 가장 먼저 공략할 사용자는 만들어 봤지만 AI 통제에 실패하고 있는 Controller 단계 학습자다.
