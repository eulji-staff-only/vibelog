정답입니다!

결과 유추하기

다음 JSP가 만들어 내는 HTML 결과는?

<% int n = 3; %>
<p><%= n * 2 %></p>
정답입니다!

<%= %>는 식의 값을 출력하므로 3 × 2 = 6이 출력됩니다.
